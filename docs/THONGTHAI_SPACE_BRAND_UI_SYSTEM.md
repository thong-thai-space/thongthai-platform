# Thong Thai Space — Brand UI System

## Brand Meaning
- Thong Thai: clear thinking, structured information, confident decisions.
- Space: breathable layout, layered depth, modular growth.

## Design Principles
1. Clarity before decoration.
2. One primary action per section.
3. Motion must guide, not distract.
4. Depth through spacing and layering, not visual noise.
5. Keep premium tone while preserving accessibility.

## Visual Language
- Primary: blue trust tone for direction and action.
- Accent: amber for emphasis and high-value moments.
- Neutrals: high-contrast text and low-noise backgrounds.

## Typography
- Display: strong, concise, high-contrast.
- Title: clear section intent.
- Body: readable line-length and spacing.

## Layout Rhythm
- Section vertical spacing should feel deliberate and calm.
- Cards and blocks use consistent radius, border, and shadow depth.
- Mobile keeps hierarchy first; not a compressed desktop.

## Motion Rules
- Default: subtle transitions.
- Heavy effects only when user explicitly opts in.
- Respect reduced motion and low-end devices.

## Interaction Rules
- Primary CTA: obvious, stable, high confidence.
- Secondary CTA: supportive, less visual weight.
- Feedback states: clear success/error/loading cues.

## Quality Checklist
1. A new visitor understands value proposition within 5 seconds.
2. Every section has one clear primary intent.
3. No decorative animation competes with readability.
4. Fixed overlays stay anchored to viewport.
5. Visual style remains consistent across Home/About/Services/Portfolio/Contact.
