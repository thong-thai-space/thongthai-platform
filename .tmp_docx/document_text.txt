The estimatedCostUsd is computed as follows: // Claude Sonnet pricing: $3 / M input tokens | $15 / M output tokens function estimateCostUsd( inputTokens, outputTokens) { const inputCost = ( inputTokens / 1_000_000) * 3 const outputCost = (outputTokens / 1_000_000) * 15 return inputCost + outputCost } // Example: 1,000 input + 2,000 output // = (1000/1 M)* 3 + (2000/1 M)* 15 // = $0.003 + $0. 030 = $0.033 USD 7. Data Flow Diagrams The following diagrams trace the key request lifecycles through the Thông Thái Space platform. 9.1 User Authentication Flow Step Actor Action Notes 1 Client POST /auth/ register ( email, password, name, turnstileToken) 2 AuthController Validate input + verify Cloudflare Turnstile 3 AuthService Hash password (bcrypt), generate verification token, create user 4 AuthRepository INSERT user → PostgreSQL 5 EmailService Send verification email via Resend API 6 Client Click verification link → GET /auth/verify?token=xxx 7 AuthService Find user by token, check expiry, mark emailVerified, generate JWTs 8 Client Receive { accessToken , refreshToken, user } Google OAuth follows the same pattern — AuthService calls loginWithGoogle( ) which upserts the user and generates the same JWT pair. 9.2 Task Management Flow Step Actor Action Notes 1 Client POST /projects/{id}/ tasks ( title, assigneeId, priority) 2 TaskController Validate + check JWT auth 3 TaskService Run DFS cycle detection on parentId tree Prevent circular subtasks 4 TaskService Validate assignee exists + belongs to project 5 TaskRepository INSERT task → PostgreSQL 6 NotificationService Create TASK_ASSIGNED notification 7 NotificationGateway Emit via Socket.IO to connected client 8 PushService Send Web Push if user is offline 9 Client Receive { id , title, status: TODO, assigneeId } 9.3 AI Proposal Generation Flow Step Actor Action Notes 1 Client POST /ai/ proposal ( requirements, budget, locale) 2 AiController Validate + check auth 3 AiService Check monthly token quota (aiQuotaUsedTokens &lt; aiQuotaLimitTokens) Throws 429 if exceeded 4 AiService Mask sensitive data (emails, phones, IDs) 5 AiService Build prompt + call Anthropic API (claude-sonnet-4-20250514) 6 Anthropic API Generate proposal, return { content , usage } 7 AiService Calculate estimatedCostUsd + increment quota 8 AiUsageAuditRepo INSERT audit record (feature, tokens, cost, durationMs) 9 Client Receive { proposal , usage: { inputTokens , outputTokens } } 9.4 Invoice Creation Flow Step Actor Action Notes 1 Client POST / invoices ( clientId, items[ ], taxRate, discount) 2 InvoiceService Validate items, compute qty * unitPrice for each 3 TaxCalculator Convert to cents → calculate tax → convert back Precision arithmetic 4 InvoiceService total = subtotal + tax - discount 5 InvoiceRepository Query last INV-YYYY-XXXX → increment sequence O( 1) indexed lookup 6 InvoiceRepository INSERT invoice + InvoiceItems → PostgreSQL 7 Client Receive { invoiceNumber , status: DRAFT, total, items } 9.5 Real-time Notification Flow Step Actor Action Notes 1 Any Service Trigger notification (e.g. task assignment) 2 NotificationService Build recipient Set: admins + owner + assignee + creator − commenter O( 1) deduplication 3 NotificationRepo INSERT notification records in parallel (Promise.all) 4 NotificationGateway sendToUser( ) via Socket.IO (online users) Real-time delivery 5 PushSubscriptionRepo Find VAPID endpoints for offline users 6 PushService Encrypt payload + send to browser push endpoint Offline delivery 10.
